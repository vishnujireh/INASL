# INASL 2027 – Frontend

React 19 + TypeScript + Vite + Tailwind CSS 4. See the root `README.md` of the project for the
full setup (backend, database, payments, emails).

```bash
cp .env.example .env
npm install
npm run dev        # http://localhost:3000 (proxies /api to http://localhost:4000)
npm run build      # production build in dist/
npm run lint       # type-check
```
